# 『キャッチミーイフユーニャン』 🐾
**Catch Me If You Nyan**

ハイパーカジュアルWeb落ち物アクションゲーム（Phaser 3 / GitHub Pages対応）

---

## 🎮 ゲーム概要
画面上部から降ってくる大好物（魚・チキン・高級缶・またたび）を左右スワイプでキャッチしてハイスコアを目指す落ち物アクションゲームです。
タマネギやチョコなどのキケン物に当たるとライフが減少。3回被弾でゲームオーバー！

### ✨ 主な機能・特徴
- **完全単一ファイル構成 (`index.html`)**: 外部画像・外部音声ファイル不要！
- **Web Audio API プログラマブル音響**: 8bit風ピコピコBGM、コンボに応じたドレミファ音階SE、ファンファーレ、被弾音を完全合成
- **1:1 相対ドラッグ操作**: スマホ画面のどこをスワイプしても指被りなくスムーズに操作可能
- **ミニフィーバーモード**: 「🌿 またたび」取得で3秒間無敵ラッシュ（ごちそう大漁＆レインボー背景）
- **プレイヤー有利な当たり判定調整**: ごちそうは吸い込みやすく（120%）、キケン物はギリギリ避けられる（60%）
- **X (Twitter) シェア & ハイスコア保存**: localStorageによる自己ベスト記録＆ワンタップSNSシェア

## 🚀 遊び方 / 起動方法

### ローカルで遊ぶ場合
本フォルダでローカルHTTPサーバーを立ち上げるか、ブラウザで直接 `index.html` を開いてください。

```bash
# Pythonで簡易サーバーを起動する場合
python -m http.server 8000
```
ブラウザで `http://localhost:8000` にアクセスしてください。

### GitHub Pagesで公開する場合
1. 本リポジトリをGitHubにプッシュ
2. リポジトリの **Settings** > **Pages** を開く
3. **Branch** を `main` (または `master`)、フォルダを `/ (root)` に設定して **Save**
4. 数分で公開URLが発行されます！
